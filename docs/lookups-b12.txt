## Main-session reading for B12
- Absent SQS VisibilityTimeout (30), Lambda Timeout (3), SAM function Timeout (3) and ALB idle (60, application only) have documented defaults above; they follow from a template only when every place the value could come from was read (Globals, Transform, a plain resource). Basis `documented`.
- The batching window: the CloudFormation page documents a default of 0 for SQS, but, as in B5, an absent window is the ASSUMED 0 s and a result resting on it is UNRESOLVED. (B5 reasoning: a deploy or console change outside the template is not corrected by it.)

## Return values of Ref and GetAtt (read 2026-11-12, UTC 14:44Z; same pages as above)
SQS queue page: "When you pass the logical ID of this resource to the intrinsic Ref function, Ref returns the queue URL." and "Arn Returns the Amazon Resource Name (ARN) of the queue."
Lambda function page: "Arn The Amazon Resource Name (ARN) of the function." "When you pass the logical ID of this resource to the intrinsic Ref function, Ref returns the resource name." (Return values section)
-> A function is followed as Ref or Fn::GetAtt [function, Arn] (a name or an ARN: both are accepted by the mapping's FunctionName). An event source ARN is followed only as Fn::GetAtt [queue, Arn]; a Ref to a queue is a URL, not an ARN, so it is not followed.
